// 05 · HOW I THINK

Intuition first. Then the math. Then the code.

This is the order I use to learn, and to teach, a technical topic. Click through it with an illustrative example: a Bayes spam detector.

Illustrative walkthrough · same order whether it's Bayes, LSTMs or SQL joins

I QUESTION THE FIRST EXPLANATION

If it doesn't match my mental model, I push back until the logic between steps is clear.

PRECISE > POLITE

Tell me which part is right, which is wrong, and why. Vague praise teaches me nothing.

IDEA ≠ BUILT ≠ TESTED

I keep proposed, in-progress and demonstrated work separate. No inflated claims.
